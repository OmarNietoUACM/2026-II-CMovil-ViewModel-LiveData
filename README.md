# Ejercicio.  Uso de ViewBinding, ViewModel, LifeData  

El ejercicio muestra información de un usuario a partir de una lista, tiene dos botones, uno para mostrar 
el siguiente usuario y el otro para mostrar el usuario previo. En el proyecto se configura **ViewBinding** 
para que el Gradel genere la classe *ActivityMainBinding*, se crea la clase UsuarioViewModel donde se guarda
el objeto usuario que se muestra en la vista, el cual se registra como observable con LiveData.

La aplicación utiliza los controles: **TextView**, **Button**.
Se utilizaron los objetos **ViewBinding**, **ViewModel** y **LiveData**
